# 校园网自动登录 Chrome 扩展

自动连接校园网，支持多运营商账号配置、断网自动重连等功能。

## 功能特性

- ✅ 自动登录校园网
- ✅ 断网自动重连
- ✅ 支持多账号配置
- ✅ 支持三大运营商（电信、移动、联通）
- ✅ 登录成功/失败通知
- ✅ 一键注销功能
- ✅ 配置导入/导出

## 安装步骤

### 1. 生成图标

1. 用浏览器打开 `create_icons.html` 文件
2. 图标会自动下载到下载文件夹
3. 将下载的 `icon16.png`、`icon48.png`、`icon128.png` 移动到 `icons` 文件夹

### 2. 加载扩展

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions/`
2. 开启右上角的「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目文件夹

## 使用说明

### 添加账号

1. 点击扩展图标打开弹窗
2. 输入学号和密码
3. 选择运营商
4. 点击「+」按钮保存账号

### 登录

1. 从下拉框选择已保存的账号
2. 点击「登录」按钮

### 自动登录设置

1. 右键点击扩展图标 → 选项
2. 开启「启动时自动登录」
3. 开启「断网自动重连」
4. 设置检测间隔（默认5分钟）

### 导出/导入配置

在设置页面可以：
- 导出配置为 JSON 文件（备份）
- 导入配置文件（恢复）

## 常见问题

**Q: 登录失败怎么办？**
A: 请检查学号、密码和运营商是否正确。

**Q: 自动登录不工作？**
A: 检查设置中是否开启了自动登录选项，以及是否保存了账号。

**Q: 如何切换运营商？**
A: 在弹窗中选择不同的运营商，或在设置中添加多个账号。

## 注意事项

- 密码保存在浏览器本地存储中，请注意账号安全
- 首次使用需要手动添加账号
- 建议定期导出配置备份
