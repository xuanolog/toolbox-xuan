# 安装与使用

## 安装

1. 从交付目录取得 `SZCU-Connect-0.1.3-debug.apk`，复制到安卓手机。
2. 打开 APK，允许本次安装。最低要求 Android 11。
3. 小米通过电脑安装时，先开启“开发者选项 → USB 调试”和“USB 安装”，保持手机解锁，在安装请求出现时确认。
4. 安装后打开 **SZCU Connect**。

这是个人调试签名版本，不是应用商店发行包。同一签名可以覆盖安装保留配置；不要为了升级直接卸载旧版。卸载会删除账号配置，签名密钥变化则无法直接覆盖安装。

## 添加配置

1. 点击首页“添加第一个配置”，或“账号管理 → 添加配置”。
2. 填写配置名称，例如“宿舍电信”。
3. Wi-Fi 名称默认 `SZCU-313-5G`，可改为你所在位置的校园热点名称，需保持大小写和空格一致。
4. 在四个运营商中选择一项。
5. 填写学工号，不加 `@telecom` 等后缀；填写数字门户密码。
6. 点击“保存配置”。可添加多个配置，在首页选择；选择会保存为下次打开时的默认配置。

配置编辑页禁止截图和录屏。密码只在手机本地加密保存，不需要发给开发者。

## 连接

1. 选择目标配置，点击“连接校园网”。
2. 第一次使用时允许“精确位置”和“附近设备/Wi-Fi”权限，并打开系统定位开关。安卓通过这些权限向应用提供 Wi-Fi 名称，应用不读取或上传定位坐标。
3. 如果尚未连接校园 Wi-Fi，在弹出的 WLAN 面板中选择目标网络，再返回应用。新版不再添加自动连接建议或额外发起保存网络请求；首次打开会移除本应用旧版留下的建议。
4. 等待认证结果；无需再次填写网页表单。连接完成后可以离开应用。

Wi-Fi 密码与数字门户密码不是一回事。本版支持无 Wi-Fi 密码、连接后需要网页认证的校园热点。

## 结果说明

| 显示结果 | 含义与操作 |
| --- | --- |
| 连接成功 | 本次登录成功或已确认同账号在线，并已通过目标 Wi-Fi 访问百度；标题与说明为绿色 |
| 当前 Wi-Fi 已联网 | 当前校园账号与所选账号及运营商一致，联网检查通过，未重复登录 |
| 正在注销 | 当前账号不同或无法可靠识别，先退出原账号，再登录所选配置 |
| 内网认证成功 | 校园内网账号已通过认证，不以访问百度为必要条件 |
| 认证成功，外网未确认 | 学校已接受认证，但暂未能通过目标 Wi-Fi 访问百度；稍后再检查 |
| 认证未通过 | 核对运营商、学工号、密码及账号服务状态；应用不会自动尝试其他账号 |
| 等待 Wi-Fi 超时 | 确认目标热点在附近、Wi-Fi 已开启，并在系统 WLAN 面板手动选择 |
| 模板或规则已变化/需要验证码 | 使用“校园网登录页”手动认证，后续更新适配器 |

点击“取消连接”会停止后续步骤。已经发出的请求无法撤回，取消不会断开手机 Wi-Fi。应用没有后台自动重连或开机启动。

## 常见问题

- **Wi-Fi 名称显示需要权限**：检查应用精确位置、附近设备权限和系统定位开关；返回后再点击连接。
- **小米拒绝 USB 安装**：打开 USB 安装后，需要电脑重新发起安装，单独开启开关不会自动弹出安装确认。
- **更新后权限提示重新出现**：部分小米系统会重新审核侧载应用权限，按手机界面重新允许即可。
- **切换账号**：选择配置本身不会断网；点击“连接校园网”后才执行切换。已有其他或无法识别的账号时自动注销、确认离线，再请求网页“返回”对应的登录入口，读取新参数登录。注销失败会停止，不继续提交密码。
- **开启流量时 Wi-Fi 有感叹号**：可以保持流量开启。应用只通过目标 Wi-Fi 登录并访问百度，同时请求系统重新检测。系统图标刷新可能延迟，不单独阻止应用显示绿色成功；若仍提示外网未确认，请告知最终提示。
- **账号文件无法解密**：应用会保留原文件并暂停编辑，不静默覆盖。不要直接清除数据；向开发者说明现象，无需提供密码。

校园网原接口使用 HTTP；应用兼容这一既有协议，只向已确认的学校地址提交凭据。电脑、手机流量或其他 Wi-Fi 能访问互联网，不等于校园 Wi-Fi 认证成功。

旧版建议的清除只涉及本应用添加的项目，不删除你手动保存的 Wi-Fi 或账号配置。Android 11–12 清除建议时系统可能短暂断开该建议连接，可在 WLAN 面板重新选择网络。
