# toolbox-xuan

个人工具箱仓库，收集常用工具和浏览器扩展。

## 目录结构

```
toolbox-xuan/
└── browser-extensions/
    └── campus-auto-login/    # 校园网自动登录 Chrome 扩展
```

## 浏览器扩展

### campus-auto-login

校园网自动登录 Chrome 扩展，支持自动填写账号密码并登录校园网。

详细说明见 [browser-extensions/campus-auto-login/README.md](browser-extensions/campus-auto-login/README.md)。
